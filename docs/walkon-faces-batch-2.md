# Walk-on faces, second batch (older and younger)

Prompts for ROADMAP debt 27: every walk-on role has one face per sex, nearly all aged 25 to 45, so every bar has the same bartender and nobody reads as young or old. This batch adds a **young** (about 20) and an **older** (about 62) face where a role does not already have one, for both sexes. Nothing else changes: the same scenes, the same painting look.

## How to use it

- Each block below is a complete prompt: the Vignette wrapper from [art-style.md](art-style.md) with the subject filled in. Paste **one block per conversation turn**, never several, so no earlier image steers the next.
- Landscape 3:2. The interface cuts the head and shoulders out of the picture (`tools/art/flavor-faces.mjs`), so the prompts ask for the head in the upper-left or upper-centre, about a third of the frame's height, face clear and unobstructed. If a result hides the face, covers it with steam or a hand, or puts the head low in the frame, regenerate it rather than keeping it.
- Save each result as the file name above its prompt (`<role>-<sex>-<band>.png`, band is `young` or `older`) and hand them back in batches. Integration (catalog entries with `age` and a `face` square, WebP at both widths, and choosing a variant per place) is done on the code side once the pictures are in; nothing in the game changes until then.
- Do the batches in order. **Batch 1** is the seven roles that turn up in the most places; the later batches can wait for how Batch 1 looks.
- Not covered: nonbinary walk-ons (walk-on art is male and female only, a walk-on's gender is the picture's) and anybody 70 or older.
