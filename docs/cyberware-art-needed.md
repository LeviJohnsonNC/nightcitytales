# Cyberware that still needs an image

None of the 96 cyberware items has art. The manifest key for each is `cyberware.<id>` (`src/data/art/manifest.json`, `itemArt`), and no such key exists yet; `CyberwarePanel`, the character sheet and the starting-gear list all show a placeholder instead.

Nine items share an id with a **gear** picture that already exists (marked ★). That picture is keyed `gear.<id>`, so it is not used for the cyberware version, but it could be reused or restyled for it.
